# ZALU design (owner: Damir)

**Complex technology. Simple experience.** Design guidelines: usability → structure → clarity → consistency → polish.

| What | Where |
|---|---|
| Token source of truth | `frontend/src/app/globals.css` (`@theme`, Tailwind v4) |
| Tokens for Figma / Tokens Studio (W3C DTCG) | `design/tokens.json`, generated by `python design/sync_tokens.py` |
| Figma builder plugin | `design/figma-plugin/` (variables, text styles, components, 6 screens, prototype) |
| Figma file | [ZALU — Product Design](https://www.figma.com/design/LaO3UPWu43VHsWocxW0Jna) |

## Build the Figma file
The Figma MCP connector on the Starter plan has a small call quota and allows 3 pages, so the whole design system is built by a local plugin instead:

1. Open the Figma file in the **Figma desktop app**.
2. Menu → Plugins → Development → **Import plugin from manifest…** → choose `design/figma-plugin/manifest.json`.
3. Run **ZALU Design System Builder**. In under a minute it creates:
   - **Cover & Foundations**: principles, colour swatches, type ramp, spacing scale;
   - **Components**: Button (Style × State), Badge, Banner, Step, Verdict, Chip (variants with text properties), KPI;
   - **Journey**: Describe → Upload → Prepare → Train → Verify → Deploy at 1280 px, built from component instances, with prototype links on each primary action (Present ▶ starts at "ZALU journey").
   - Variables collection `ZALU / Tokens` (colour, spacing, radius, with `var(--color-…)` code syntax) and Inter text styles.
4. Running it again replaces what it created before (it only removes nodes it named itself).

After changing a colour in `globals.css`: `python design/sync_tokens.py`, then re-run the plugin. `--check` fails CI if tokens drift or a text colour drops below WCAG AA.

## Rules applied in code and Figma
- **One primary action per screen.** Secondary actions use the Secondary/Ghost button.
- **Status never by colour alone**: badges and banners carry an icon and text (✓ ! ✕ ◆ i); false-alarm boxes are dashed, misses solid.
- **Contrast** (checked by `sync_tokens.py`): text ≥ 4.5:1 via `*-ink` tokens (warning `#B46D12` is used for fills/borders only; its text variant is `#8A5208`), input borders ≥ 3:1 (`control`).
- **Keyboard**: visible focus ring, skip link, stepper as an ordered list with `aria-current`, box list for annotation edits without a mouse, model comparison selectable by button.
- **Motion**: short fades only, disabled under `prefers-reduced-motion`.
- **Sample data** is always marked ◆ in purple, in the app and in Figma.
- **Advanced ML settings are hidden** behind "Advanced settings" (Train step).
